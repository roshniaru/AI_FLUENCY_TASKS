
# From Prompt to Action: Understanding LLMs, Tools, and Agents

## 1. Objective

The objective of this task is to understand the difference between a Large Language Model (LLM) working independently and an LLM using an external tool. A calculator tool is used to compare their behaviour on calculation-based and general knowledge questions.

## 2. Scenario

The scenario is based on a college fee assistant. Students may ask questions about course fees, laboratory charges, scholarship calculations, and the meaning of scholarships.

The system is tested in two ways:
- A plain LLM that answers questions without using external tools.
- An LLM that can call a calculator tool when mathematical calculations are required.

## 3. What Is a Large Language Model?

A Large Language Model (LLM) is an AI model trained on large amounts of text to understand questions and generate human-like responses. It can explain concepts, answer questions, summarize information, and solve many problems.

In this task, the LLM answers questions about scholarships and college fees.

## 4. What Is an AI Agent?

An AI agent uses an LLM to decide what action is needed to complete a task. It may use external tools, observe their results, and then produce a final answer.

In this project, the LLM can use the calculator tool for arithmetic questions.

## 5. What Is a Tool and a Tool Call?

A tool is a function that performs a specific operation outside the LLM's normal text generation process.

The calculator tool evaluates arithmetic expressions and returns the result as text.

A tool call happens when the LLM requests the calculator to perform a calculation. The program executes the function and sends its result back to the LLM, which can then prepare a final answer.

## 6. Tool Schema

The calculator tool is described to the LLM using a tool schema. The schema contains:
- Tool name: calculator
- Description: Calculates mathematical expressions
- Input parameter: expression
- Parameter type: string

The schema helps the LLM understand when and how to request the tool.

## 7. Tool Call Flow

The tool-enabled program follows these steps:

1. The user asks a question.
2. The LLM receives the question and available tool description.
3. The LLM decides whether a tool is required.
4. If calculation is required, the LLM requests the calculator tool.
5. The Python calculator function evaluates the expression.
6. The tool result is returned to the LLM.
7. The LLM generates the final answer.

For questions that do not require calculations, the LLM may answer directly without calling the tool.

## 8. Comparison Between Plain LLM and Tool-Enabled LLM

| Basis | Plain LLM | LLM with Calculator Tool |
|---|---|---|
| Tool availability | No external tool | Calculator tool available |
| Calculation | Generated by the model | Can use the calculator result |
| General questions | Answers directly | Can answer directly |
| Tool execution | Not available | Tool calls and results can be observed |
| Reliability | Depends on the generated answer | Arithmetic can be checked using the calculator |
| Process | User question to model answer | User question to model, optional tool execution, final answer |

## 9. Questions Used in the Experiment

### Question 1: Scholarship Calculation

CS101 costs Rs. 12,000 and AI202 costs Rs. 18,000. A 10% scholarship applies to the combined fee.

Expected calculation:
- Combined fee = Rs. 30,000
- Scholarship = Rs. 3,000
- Final fee = Rs. 27,000

### Question 2: General Knowledge

Explain what a scholarship means in simple words.

This question tests whether the LLM can explain a general concept without requiring an external calculator.

### Question 3: Total Fee

Three courses cost Rs. 12,000, Rs. 18,000, and Rs. 15,000. An additional laboratory charge is Rs. 4,500.

Expected total = Rs. 49,500.

## 10. Observations

The plain LLM and the tool-enabled LLM were tested using the same three questions.

The plain LLM generated answers directly. The tool-enabled LLM had access to the calculator function and could use it for arithmetic calculations.

The general knowledge question did not require a calculator. The calculation questions could benefit from using the calculator tool.

The actual answers and tool-call behaviour should be recorded based on the terminal outputs from both programs.

## 11. Suitability

A plain LLM is suitable for explanations, summaries, and general knowledge questions where an external calculation is not necessary.

An LLM with a calculator tool is useful when a task requires arithmetic that should be checked using a separate function.

For a college fee assistant, combining an LLM with a calculator can provide both natural-language explanations and verifiable arithmetic results.

## 12. Conclusion

This task demonstrates how an LLM can work independently or use a tool to complete a task. The plain LLM generates responses directly, whereas the tool-enabled program can request a calculator function and use its output in the final answer.

The experiment helps explain the relationship between an LLM, a tool schema, a tool call, and an AI agent workflow.
